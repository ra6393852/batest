Windows용 읽기 전용 바카라 분석기를 추가합니다. Chrome 게임 창의 숫자 그림판을 수집하고, A/B/C/D의 다음 4회차 답을 결과 전에 저장해 O/X와 누적 적중률을 갱신합니다. 그림판별 SQLite 기록을 보존하며 자동 베팅과 사이트 보안 우회는 구현하지 않습니다.

0.5.7에서는 프로그램 시작 때 관리자 암호를 요구합니다. 잠금 상태에서는 기록 조회, 이미지 입력, 캡처와 브라우저 등 주요 IPC 호출도 거절합니다. 실제 암호는 소스에 넣지 않고 salt와 scrypt 검증값만 저장합니다. 반복 오류를 제한하고 재시작하면 다시 잠급니다. 테스트 자격은 별도 임시 프로필의 smoke 실행에만 적용하며 일반 실행에서는 무시합니다.

기본 1회차부터 보기는 지난 판과 다음 4회차를 하나의 표에 번호순으로 표시합니다. 사전 기록이 없는 판은 목표 판/점수를 가리고 앞선 연속 기록으로만 다시 계산해 과거 검증으로 표시합니다. 첫 판은 8덱 이론 기준이며 누락 구간은 학습을 다시 시작합니다. 과거 검증률은 실제 사전 예측 적중률과 구분하고 기존 forecasts/settlements를 수정하지 않습니다. 실시간 보기로 전환하면 최근 사전 채점과 다음 4회차에 집중합니다.

반복 통계는 변경 전까지 캐시하고 외부 호출자의 수정은 격리합니다. 결과/점수/확인 대기 변경과 실패 복구에는 캐시를 비웁니다. 변하지 않은 미리보기 PNG는 다시 보내지 않으며 관측 시각과 상태는 계속 전달합니다. 프런트엔드 과거 검증과 회차 인덱스 및 과거 행도 데이터 변경 때만 계산합니다. 기존 별도 판독 워커, 영역 캐시, 2배 판독, 숫자 처리 큐와 모니터 유지를 함께 사용합니다.

검증 대상은 단위 111개, Linux Electron 9개, Windows 소스/실제 무설치 EXE 각 10개입니다. 잠금 전 주요 API 거절·오류 암호·정상 해제·재실행 재잠금, 1회차~30회차 단일 표와 과거/실시간 통계 구분, 목표와 미래 점수 가림·누락 구간 초기화, SQL 조회 없는 캐시 재사용·외부 수정 격리·새 결과/점수 갱신, 동일 PNG 생략·관측 시각 유지와 기존 실시간 수집/OX/SQLite 보존을 검사합니다. 실제 관리자 검증값의 일치는 로컬에서 별도로 확인하며 실제 암호를 CI/로그에 넣지 않습니다.

배포는 Windows 무설치 ZIP 전체입니다. README에 실행 및 빌드 방법을 기록했습니다. 실제 Evolution 화면과 패턴의 예측 우위는 미검증입니다. 승자 점수만으로 남은 카드를 알 수 없어, 정확도 보강에는 같은 슈 시작부터 양쪽 실제 카드와 장수가 추가로 필요합니다.
