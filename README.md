# Baccarat Live Analyzer

Windows 10/11용 읽기 전용 바카라 그림판 통계 프로그램입니다. 현재 저장소는 `ra6393852/batest`이며 Electron/React/TypeScript와 SQLite를 사용합니다.

**0.4.4는 클립보드 붙여넣기 전용 화면입니다.** 화면에는 이미지 붙여넣기, 인식 결과 확인·저장, 방별 기록과 A/B/C/D 통계가 있습니다. 기존 Chrome 연결·테스트·프로필·직접 입력·시뮬레이션·수동 결과 입력·CSV 버튼은 제거했습니다.

## 무설치 실행과 사용

1. 기존 프로그램을 닫고 무설치 ZIP **전체**를 폴더에 풉니다.
2. **Baccarat Live Analyzer.exe**를 실행합니다. EXE와 `resources` 등의 폴더·파일을 함께 유지하세요.
3. 이미지가 클립보드에 있으면 **Ctrl+V** 또는 **클립보드 이미지 붙여넣기 (Ctrl+V)**를 누릅니다. 새 캡처가 필요한 경우에만 `Win+Shift+S`를 사용합니다.
4. 미리보기와 인식한 B/P/T 순서를 확인합니다. 잘못 읽은 결과는 각 선택 상자에서 수정합니다. 빅로드의 초록 타이 표시가 있으면 원본을 보고 횟수를 입력합니다.
5. 방 이름, 기록 그룹/슈, 이미지 첫 결과의 기록 번호를 확인하고 확인 체크 → **확인한 그림판 기록 저장**을 누릅니다.
6. 선택한 방·슈의 결과 수, 출현 비율, 연속 횟수와 다음 회차 A/B/C/D 추정을 확인합니다.

Node.js나 설치 작업 없이 실행합니다. 기록은 기존 Electron `userData`의 SQLite에 저장하며 같은 Windows 계정의 기존 기록 저장 위치를 유지합니다. 이미지와 파일 경로는 DB에 저장하지 않습니다.

## 그림판 인식 범위

현재 지원 대상은 결과 7개 이상인 6행 비드로드와 빅로드입니다. 비드로드는 위→아래, 왼쪽 열부터 읽고 빅로드는 B/P 연속과 꺾임을 따라 읽습니다. 쌍 표시를 별도 결과로 추가하지 않으며, 초록 타이 횟수는 사용자가 확인합니다.

0.4.4에서는 회색 바깥 테두리 대신 **내부 격자 간격**으로 6행 경계를 찾는 경로를 추가했습니다. 격자 사이의 추가 회색 획을 건너뛰고, 바깥 세로 경계가 흰색일 때 첫/마지막 결과 열이 누락되지 않도록 검사합니다. 잘려서 보이지 않는 행·결과 열을 임의 복원하지 않습니다.

인식 실패 때도 원본 미리보기와 이미지 불러오기 성공을 표시합니다. 결과를 확정하지 못한 이미지는 저장하지 않으며 이전 확인 ID도 무효화합니다. 이번 수정은 테두리·겹친 회색 획을 재현한 fixture로 검증했고, 사용자 첨부 원본의 픽셀 파일을 직접 실행한 결과는 아닙니다. 모든 워터마크나 화면 배율에서 인식된다고 보장하지 않습니다.

같은 방·슈·시작 번호로 다시 넣으면 중복 저장을 막습니다. 충돌은 기존 기록을 유지하고 확인 대기로 보냅니다. 새 슈는 그룹 이름을 바꾸세요. 실제 회차를 모르면 독립 그룹에서 1부터 번호를 부여합니다. 방·슈·실제 회차 번호를 이미지에서 자동 판독하지 않습니다.

## 확률과 채점

| 방식 | 분포의 근거 |
| --- | --- |
| A | 표준 8덱 이론값: B 45.86%, P 44.62%, T 9.52% |
| B | 최근 최대 20회 결과의 출현 비율 |
| C | 현재 B/P 연속 상태와 유사한 과거 상태의 다음 결과 |
| D | 해당 방의 과거 결과 패턴과 전환 통계 |

B/C/D는 이론값으로 평활한 과거 패턴 추정입니다. 남은 카드의 구성은 알 수 없으며 실제 다음 판의 정확한 확률이나 예측 우위가 입증된 값이 아닙니다. 누락 회차나 슈 경계를 가로질러 패턴을 연결하지 않습니다.

붙여넣은 그림판은 **과거 기록**으로 저장합니다. 다음 추정은 먼저 보존하지만 이미지 업데이트를 사후 O/X 채점하지 않습니다. 따라서 클립보드 입력만 사용하면 실시간 적중률 검증 횟수가 늘지 않습니다. 기존에 저장된 사전 예측/채점 이력은 유지합니다. 타이는 B/P 연속을 끊지 않으며 타이 제외 적중률은 실제 T 회차만 제외합니다.

## 개발과 검증

Windows에서 Node.js 24와 Git을 준비한 뒤 저장소 루트에서:

```powershell
npm ci
npm run setup:electron
npm run build
npm start
```

Electron 44 실행 파일은 `setup:electron`로 별도 다운로드합니다. TLS/체크섬 검증을 유지합니다.

```powershell
npm test
npx --no-install playwright install chromium
npm run test:desktop
npm run dist:win
```

Windows ZIP 생성 위치: `release/Baccarat-Live-Analyzer-0.4.4-x64-Portable.zip`.

[Windows CI](.github/workflows/windows.yml)는 소스 테스트, ZIP 빌드, 실제 압축 해제한 EXE의 통합 테스트를 수행하고 검증한 폴더 전체를 `baccarat-windows-x64-portable` 아티팩트로 제공합니다. 설치 파일을 포함하지 않고 실행 프로토콜을 자동 등록하지 않습니다. 코드 서명 인증서는 설정하지 않았습니다.

현재 단위 테스트는 70개, Linux Electron 테스트는 4개입니다. Windows에서는 내부 Chrome 모듈 테스트를 포함해 소스/무설치 EXE에서 각각 5개를 실행합니다. 테스트용 DOM 수집과 수동 입력은 UI 버튼 대신 기존 내부 API로 검사합니다. Linux 검증은 `bash scripts/test-cloud.sh`이며 [개발 환경 안내](docs/cloud.md)와 [검증 기록](docs/validation.md)를 참고하세요.

사이트 수집 모듈은 별도로 유지되며 기본 실행에서 Chrome 연결 서버를 시작하지 않습니다. 개발용 명시적 `--enable-chrome-bridge` 실행만 연결 서버를 시작합니다. 실제 Evolution 자동 수집과 사용자 화면의 인식률은 미검증입니다.

자동 베팅, 베팅 클릭/금액 입력, 로그인 비밀번호 수집, 민감한 세션 정보 로그, 보안 정책 우회 기능을 구현하지 않습니다.
