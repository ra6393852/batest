# 검증 기록

0.5.0: 게임 창을 한 번 선택한 뒤 1초마다 왼쪽 아래 이미지를 가져오고 방 이름·전체 결과 수·비드로드를 두 번 확인하여 저장합니다. 결과 수의 숫자 신뢰도를 기호와 구분해 #23의 판독 보류를 수정했습니다. 실제 native desktopCapturer로 로컬 게임 창 22→23회차 이미지 갱신, 사전 O/X 채점, A→B방 11회차 독립 복원과 A기록 보존을 검사합니다. 숫자 이미지22회차→26회차에 대해 A/B/C/D 4회차 답 보존·자동 채점·최신27~30회차 생성·확인된 점수 저장·재시작 보존을 검사합니다. 점수 OCR은 미확인 숫자를 비우며 테스트에서도 틀린 값을 허용하지 않고 비운 점수는 원본대로 확인 입력합니다. SQLite v1→v2 이관 시 기존 예측/결과/채점 ID 보존·새 horizon3/4·점수 불변성·외래키도 검사합니다. 단위91개, Linux Electron8개 및 Windows 소스/무설치EXE 각각9개 대상입니다. 최신 CI 결과에서 통과 여부를 확인하세요. 사용자 첨부 원본 픽셀/실제 Evolution 게임 화면은 직접 검증하지 않았습니다.

0.4.6: 설명/입력/표 글씨를 키우고 원본 100%·150% 확대 전환을 추가했습니다. 분석과 미리보기에 원본 픽셀을 유지합니다. 빅로드 초록 타이에 1회 기본값을 넣고 별도 T 회차로 펼쳐 번호·합계를 표시하며, 타이 횟수 확인 후 저장합니다. 재현한 261×116 그림판의 B/P 14원 + T1회에 대해 13회차 T·총15회·다음16회차를 검증했습니다. 두 타이로 변경 시 총16회/후속번호/확인 체크 해제, 횟수 미입력 시 저장 금지와 원본 261px/확대391.5px 너비도 검사합니다. 단위82개와 Linux Electron6개 통과. Windows 소스/무설치 EXE는 각각7개 대상이며 최신 PR checks에서 확인합니다. 첨부 원본 파일 대신 같은 배치를 재현한 fixture를 사용했습니다.

0.4.5: 격자 판독과 독립적으로 빈 원의 중심·둘레로 빅로드를 읽는 경로를 추가했습니다. 타이 사선의 색을 함께 연결하고 24방향 둘레·빈 중심을 검사한 뒤 소수점 간격의 6행에 맞춥니다. 단위 테스트 78개와 Linux Electron 5개 통과. 새 테스트는 격자 없는 12/18.6/23.4픽셀 간격, 매우 흐린 격자, 초록 사선/쌍 표시, 6연속·충돌 꺾임, 마지막 원 가림·6행 잘림·두 그림판 거절, 실패 진단 수치를 검사합니다. 실제 OS 클립보드의 PNG를 Ctrl+V로 읽고 타이 확인 후 순서 그대로 저장, 다음 회차 A/B/C/D 생성까지 검사했습니다. Windows에서는 소스/무설치 EXE 각각 6개 테스트를 실행합니다. 사용자 원본 픽셀 파일은 접근하지 못해 재현 fixture를 사용했으며 원본 인식 성공을 주장하지 않습니다.

0.4.4: 클립보드 붙여넣기/확인 저장 전용 화면으로 정리했습니다. Chrome/테스트/프로필/파일/직접 입력/시뮬레이션/수동 결과/CSV 버튼을 제거하고 기본 Chrome 서버 자동 시작도 중단했습니다. 회색 바깥 가로선이 없는 6행 빅로드, 추가 회색 획, 6회 연속, 바깥 세로선이 없는 첫 결과 열, 잘린 마지막 결과 열을 검증합니다. 사용자 원본 픽셀 대신 재현 fixture를 사용했습니다. 총 단위 테스트 70개와 Linux Electron 4개, Windows 소스/무설치 각 5개 대상입니다. 내부 수집 테스트는 UI 버튼 대신 기존 API를 사용하며 실제 클립보드에서는 테두리 없는 그림판을 읽고 확인·중복 방지·저장·다음 추정을 검사합니다.

0.4.3: 결과를 읽지 못하는 실제 OS 클립보드 이미지를 붙여넣어 원본 미리보기/불러오기 성공/인식 실패 표시를 확인하고, 이전 결과 확인 ID와 통계 저장을 거절하는 검사를 추가했습니다. 이미지 없는 클립보드 오류와 판독 실패를 구분하며 이후 정상 그림판 붙여넣기의 복구도 검사합니다. 그림판 판독 알고리즘 자체를 변경하거나 사용자 원본 인식이 성공했다고 주장하지 않습니다. 기존 64개 단위 테스트, Linux Electron 4개 및 Windows 소스/무설치 EXE 각 5개 검사에 포함합니다.

0.4.2: Windows 배포를 설치 EXE에서 무설치 ZIP으로 변경했습니다. Windows CI는 실제 ZIP을 새 폴더에 풀고 EXE 직접 실행, 클립보드 붙여넣기, 확인 후 저장, 재시작 기록 복원, 패키지의 OCR/Chrome 확장을 검사합니다. 설치 파일을 포함하지 않고 실행 프로토콜 등록이 바뀌지 않는지도 확인합니다. 아티팩트에는 검증한 폴더 전체를 포함합니다. 검증 결과는 최신 PR checks에서 확인합니다.

0.4.1 (한국 시간 2026-10-14): 단위 테스트 64개 및 Linux Electron 테스트 4개 통과. 추가 테스트는 실제 OS 이미지 클립보드를 사용해 대시보드 Ctrl+V, 방 이름 입력칸 Ctrl+V, 직접 입력칸의 기본 메뉴 붙여넣기, 일반 텍스트 붙여넣기 유지, 이미지 없는 클립보드 오류와 이전 미리보기 제거, 다시 붙여넣기, 확인 전 DB 미저장을 검사합니다. Windows 소스·설치 EXE에서도 같은 검사를 수행하도록 기존 CI에 포함했습니다. 실제 Windows 캡처 도구와 사용자 사이트 화면의 인식률은 별도 확인이 필요합니다.

Linux의 `--no-sandbox`는 컨테이너 사용자 네임스페이스 제한 때문에 로컬 fixture 전용 테스트에서만 사용합니다. 해당 `--smoke-test`는 실제 사이트 접속을 거절하고 테스트 전용 DB/세션을 사용합니다. Windows 및 일반 앱 실행에는 적용하지 않습니다.

시험 데이터의 높은 적중률을 실제 게임 정확도로 표현하지 않습니다. 통계는 동일 목표 회차에서 사전에 저장한 A/B/C/D 분포를 비교하며, 과거 데이터의 사후 맞추기는 제외합니다.
