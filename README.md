# Baccarat Live Analyzer

Windows 10/11용 **읽기 전용** 바카라 결과 기록·통계 비교 Electron 앱입니다. React/TypeScript, 로컬 SQLite, 로컬 텍스트 OCR, electron-builder를 사용합니다. 현재 연결된 저장소 `ra6393852/batest`에서 개발합니다.

**0.4.1은 복사·붙여넣기 흐름을 개선한 기존 프로그램 수정본입니다.** Windows에서 `Win+Shift+S`로 그림판만 캡처한 뒤 프로그램으로 돌아와 `Ctrl+V`를 누르면 원본 미리보기와 인식 결과가 나옵니다. 입력칸에 커서가 있어도 이미지 붙여넣기가 동작하며 일반 텍스트 붙여넣기도 유지됩니다. Chrome 로그인·확장·사이트 프로필 없이 이미지를 읽고, 사용자가 B/P/T 순서를 확인한 뒤 A/B/C/D 통계를 볼 수 있습니다. 실시간 에볼루션 자동 수집과 별개인 테스트 기능입니다.

## 먼저 테스트하기: 그림판 이미지 분석

1. 기존 앱을 닫고 **0.4.0 설치 EXE**로 설치합니다.
2. Chrome 게임 화면에서 `Win+Shift+S`를 누르고 **그림판만 드래그**합니다. 파일 저장 없이 프로그램으로 돌아와 `Ctrl+V` 또는 **캡처 붙여넣기 (Ctrl+V)**를 누릅니다. 그림판 이미지가 이미 복사되어 있으면 바로 붙여넣으면 됩니다. 기존 **그림판 이미지 분석** 파일 선택도 사용할 수 있습니다.
3. 자동으로 찾은 원본 영역과 인식한 B/P/T 순서를 비교합니다. 잘못 읽은 결과는 각 선택 상자에서 수정합니다.
4. **방 이름**, **기록 그룹 / 슈**, **이미지 첫 결과의 기록 번호**를 지정합니다. 실제 회차를 모르면 독립 그룹에서 1부터 번호를 부여합니다. 게임의 실제 회차를 자동 알아낸 번호가 아닙니다.
5. 확인 체크 후 **확인한 그림판 기록 저장**을 누릅니다. 해당 방·슈의 통계와 다음 회차 추정이 표시됩니다.

지원 형식은 결과 7개 이상인 **6행 비드로드**와 **빅로드**입니다. 작은 원이 붙거나 흰 글자/쌍 표시가 있어도 회색 격자 칸별 색을 읽는 경로를 추가했습니다. 비드로드는 위→아래 6개씩, 왼쪽 열부터 B/P/T를 읽습니다. 빅로드는 B/P 연속의 아래 이동·바닥 꺾임·충돌 꺾임을 따라 읽고 아래 파생 로드를 제외합니다. 초록 타이 표시는 횟수를 원본과 확인해 입력해야 저장됩니다. 숫자를 임의로 확정하지 않습니다. 여러 그림판이나 설명되지 않는 칸은 자동 선택하지 않습니다. 파일은 최대 10MB/1,200만 픽셀입니다. 실제 사용자의 원본 픽셀을 이용한 인식률 측정은 아직 하지 못했고, 제공된 작은 그림판 형식을 재현한 테스트를 사용했습니다.

같은 방·슈·시작 번호의 이미지는 중복 저장하지 않으며, 결과가 충돌하면 기존 기록을 유지하고 확인 대기로 보냅니다. 새 슈는 그룹 이름을 바꾸세요. 이미지와 파일 경로는 DB에 보관하지 않습니다. 확인한 결과만 `manual` 출처의 **과거 기록**으로 저장합니다. 이미지 업데이트도 과거 기록이므로 사후 O/X 채점하지 않습니다. 다음 추정은 만들지만 이 기능만으로 실시간 적중률 검증을 할 수는 없습니다.

0.2.0부터 사이트 로그인·에볼루션 접속은 **일반 Chrome**에서 수행합니다. Chrome 확장의 **프로그램 실행** 버튼이 설치된 분석기를 열고 로컬 연결을 자동으로 다시 맺습니다. 기존 내장 브라우저의 제공자 리디렉션 차단에 의존하지 않습니다.

**실제 에볼루션 결과 자동 인식은 아직 미검증입니다.** Chrome 연결과 결과 인식은 별개이며, 허용된 방·슈·회차·결과 프로필이 없으면 사이트 데이터를 수집하지 않습니다. 로그인 정보나 Chrome 쿠키를 분석기로 가져오지 않습니다.

## 인식 실패 시에도 시작하기: 직접 입력과 수동 실시간 검증

1. **B/P/T 직접 입력**에 과거 결과를 순서대로 적습니다. **비드로드 전사 예시 38회**는 사용자가 제공한 첫 비드로드를 눈으로 전사한 예시이며 원본 확인이 필요합니다. 실제 자동 수집 기록이 아닙니다.
2. **입력 기록 확인** → 순서/방/슈/시작 번호 확인 → 확인 체크 → **확인한 그림판 기록 저장**을 누릅니다. 처음 한 결과부터 시작할 수 있습니다.
3. 오른쪽 **수동 실시간 검증**에서 다음 회차 A/B/C/D의 예상과 B/P/T 분포를 확인합니다. 이 값은 SQLite에 먼저 저장되어 있습니다.
4. 새 실제 결과가 나오면 **뱅커/플레이어/타이 결과 기록**을 누릅니다. 기존 사전 예측을 O/X로 채점하고 다음 회차 추정을 저장합니다. 최신 회차가 다른 경로로 갱신되면 오래된 입력은 거절합니다. 테스트 방에는 실제 수동 결과를 섞지 않습니다.

이는 사용자가 결과를 직접 입력하는 검증입니다. 실제 게임의 발생 시각은 자동 확인하지 못합니다. 사이트 자동 수집·자동 베팅 기능이 아닙니다. 과거 이미지 재입력은 계속 역사 기록으로 처리하며 사후 채점하지 않습니다.

**시뮬레이션 실행**은 처음 10개 기록부터 한 회차씩 미래 결과를 제외해 A/B/C/D를 비교합니다. 38개 예시에서는 같은 28개 목표를 비교합니다. 데이터가 과거에 이미 존재하는 오프라인 시험이며 실제 실시간 적중률/DB 기록에 합산하지 않습니다. 시험 성적이 높아도 다음 판 정확도를 보장하지 않습니다.

## 설치 후 사용: Chrome → 프로그램 실행

처음 한 번:

1. **0.4.1 설치 EXE**로 앱을 설치하고 실행합니다. Chrome 연결은 0.2.0부터 있습니다.
2. 앱의 **Chrome 확장 설치 폴더**를 누릅니다.
3. Chrome에서 `chrome://extensions`를 열어 개발자 모드를 켜고 **압축해제된 확장 프로그램 로드**로 그 폴더를 선택합니다. 확장을 도구 모음에 고정합니다.
4. 바카라 탭에서 확장 아이콘을 누르고, 앱에 표시된 **6자리 연결 코드**를 입력해 **프로그램과 연결**을 누릅니다.
5. **현재 바카라 탭 읽기 허용**을 누릅니다. 게임이 다른 도메인의 iframe에 있으면 해당 제공자 도메인도 개별적으로 허용합니다. 인증된 전체 로그인 링크는 입력하지 않습니다.

이후에는 **Chrome에서 로그인 → 에볼루션 방 입장 → 바카라 분석기 확장 아이콘 → 프로그램 실행**만 누릅니다. 첫 실행 시 Chrome의 외부 앱 열기 확인이 나올 수 있습니다. 이미 실행 중이면 기존 앱 창을 앞으로 가져옵니다. 확장은 앱 재시작 후 자동 재연결하며 Chrome 서비스 워커가 쉬고 있으면 최대 약 30초 걸릴 수 있습니다.

연결이 성공해도 **결과 인식 프로필 미설정**으로 표시되면 아직 실제 통계를 수집하는 상태가 아닙니다. 실제 제공자가 허용한 결과 인식 프로필을 검증해 가져와야 합니다. 자동 수집이 검증됐다고 표시하거나 샘플 데이터를 실제 결과로 대체하지 않습니다.

### 에볼루션이 별도 창으로 열린 경우

앱의 **게임 창 확인**을 누르면 확장의 연결 화면을 일반 Chrome 탭으로 엽니다. 새 게임 창에 확장 아이콘이 없어도 사용할 수 있습니다. **열린 게임 창 확인**을 눌러 처음 한 번 선택적 탐색 정보 권한을 허용하고, 표시된 창·iframe 중 게임 도메인의 **이 게임 도메인 읽기 허용**을 누릅니다. 새 도메인은 자동으로 권한을 얻지 않습니다. 확인은 허용된 탭의 새 창 자식, 팝업 창과 그 프레임을 대상으로 하며, 도메인만 표시·전송하고 로그인 링크·세션 URL은 저장하지 않습니다.

0.2.0 확장을 이미 설치했다면 앱 업데이트 후 `chrome://extensions`에서 해당 확장의 **새로고침**을 누르세요. 권한 확인 후에도 해당 화면의 인식 프로필이 없으면 자동 수집하지 않습니다. 앱은 읽기 권한 필요 / 프로필 없음 / 정보 찾지 못함 / 결과 인식을 구분해 표시합니다.

## 사용 가능한 기능

- 한국어 대시보드, Chrome 확장, 사용자별 1회 연결 및 자동 재연결.
- 그림판 이미지 판독·원본 영역 미리보기·결과 수정·확인 후 저장. 사이트 연결 없이 사용.
- 새 게임 창·iframe 도메인 확인과 도메인별 읽기 권한 안내.
- 확장의 프로그램 실행 버튼과 Windows `baccarat-analyzer://connect` 연결.
- **로컬 테스트 화면**에서 방·슈·회차·B/P/T를 영역 지정 없이 자동 판독.
- 명시적 DOM 마커 기반 수집 어댑터, 허용된 JSON 프로필 가져오기.
- 92% 미만 인식 신뢰도는 확인 대기. 중복 결과 방지와 충돌 거절.
- 방·슈별 SQLite 영속 저장, 재실행 후 복원, 이전 방/슈 조회.
- A/B/C/D 다음 회차 분포와 2회차 앞 사전 예측을 수정 불가능한 기록으로 보존.
- 동일 회차 O/X, 타이 제외 적중률, 최근 10/30/100, Brier 점수와 로그 손실.
- B/P/T 출현 비율, 연속·최장 연속·전환 빈도, 비드로드와 CSV 내보내기.
- 로컬 영어 OCR 모델과 자동 선택자 기반 결과 텍스트 영역 인식 도구. 실제 사이트에 대한 OCR은 미검증.

자동 베팅, 베팅 클릭/금액 입력, 비밀번호·쿠키 별도 수집, 보안 우회, 결과 변경 기능은 없습니다. 로컬 연결은 `127.0.0.1:38741`에만 열리며 사용자 연결 코드로 인증한 확장만 수집 데이터를 전달합니다. Chrome의 사이트 읽기 권한은 선택한 HTTPS 도메인별로 처음 한 번 허용합니다.

## 실행

Windows 10/11 x64에 Node.js 24 LTS와 Git을 설치한 뒤 저장소 루트에서:

```powershell
npm ci
npm run setup:electron
npx --no-install playwright install chromium
npm run build
npm start
```

Electron 44는 실행 파일 다운로드를 별도 `setup:electron` 단계로 제공합니다. 공식 다운로드의 체크섬과 TLS 검증을 유지합니다. 설치 파일 사용자는 Node.js가 필요하지 않습니다.

앱에서 **테스트 화면**을 누르면 6개 기존 결과를 가져옵니다. `새 결과 B/P/T`, `방 이동`, `새 슈` 버튼은 실제 베팅과 무관한 테스트 이벤트입니다. 새 결과가 확정되면 기존 사전 예측을 채점하고 다음 예측을 저장합니다. 실제 사이트에서는 허용된 어댑터가 검증되기 전 자동 수집이 꺼져 있습니다.

## 확률과 채점 규칙

| 방식 | 분포의 근거 |
| --- | --- |
| A | 표준 8덱 이론값: B 45.86%, P 44.62%, T 9.52% |
| B | 연속으로 관측된 최근 최대 20회 출현 비율 |
| C | 현재 B/P 연속 길이와 같은 과거 상태의 다음 결과 |
| D | 해당 방의 전체 수집 이력에서 최근 2개 결과 패턴의 다음 결과 |

B/C/D는 이론값을 10회 분량의 사전 가중치로 넣어 평활합니다. 이는 검증된 예측 우위가 아니라 과도한 0%/100% 추정을 줄이는 모델 선택입니다. **그림장만으로 실제 다음 판의 확률을 정확히 알 수 없습니다.** 모델마다 표본 수를 표시하며 30개 미만은 표본 부족으로 표시합니다. 남은 카드 기반 확률 계산은 구현하지 않았습니다.

- 이미 보인 과거 결과는 사후 채점하지 않습니다. 최초 판독 이후의 결과와 기존 예측만 비교합니다.
- 실제 발생 시각이 제공되면 예측이 그 시각보다 먼저 저장돼야 합니다. 없으면 최초 관측 시각을 사용하므로 실제 발생 전 저장의 완전한 검증은 불가능합니다.
- 30회차 기준의 32회차 예측과 31회차 기준의 32회차 예측은 따로 보관합니다. 2회차 앞 추정은 다음 B/P/T 분기를 각 모델의 확률로 가중 합산합니다.
- 타이는 일반 O/X에 포함하며 B/P 연속을 끊지 않습니다. 타이 제외 적중률은 **실제 결과가 T인 회차**만 제외합니다.
- 방식 비교는 A/B/C/D 모두 채점된 동일 회차의 **1회차 앞 예측**만 사용합니다. 2회차 앞 예측은 이력/CSV에서 별도로 볼 수 있습니다.
- 확률 오차인 Brier(3분류 합산, 0~2)와 로그 손실(자연로그)은 낮을수록 좋습니다. 실제 게임에서 A보다 우수한 방식은 아직 입증되지 않았습니다.
- 누락 회차나 슈 경계를 가로질러 패턴/연속을 연결하지 않습니다.

## 검증

```powershell
npm test
npm run test:desktop
```

단위 테스트는 분석 분포, 미래 데이터 누출 방지, 중복/충돌, 확인 대기, 불변 예측, 타이 채점, CSV, 재시작 저장을 검증합니다. Electron 테스트는 실제 앱에서 테스트 화면 자동 판독, 점수 갱신, 방/슈 이동, 재시작, 원격 페이지의 Node/API 격리와 로컬 OCR을 확인합니다. 실제 사이트에 로그인하거나 게임을 진행하는 테스트는 포함하지 않습니다.

Linux 클라우드 전용 준비와 검증은 [docs/cloud.md](docs/cloud.md)를 참고하세요. Windows CI는 기본 Chromium sandbox를 유지합니다.

## Windows 설치 EXE 빌드

Windows에서:

```powershell
npm ci
npm run setup:electron
npx --no-install playwright install chromium
npm test
npm run test:desktop
npm run dist:win
```

생성 위치: `release/Baccarat-Live-Analyzer-0.4.0-x64-Setup.exe`. Chrome 확장 파일은 앱의 `resources/chrome-extension`에 함께 설치합니다.

[.github/workflows/windows.yml](.github/workflows/windows.yml)은 PR/main push/수동 실행에서 단위 테스트, 데스크톱 테스트, x64 NSIS 빌드, 설치 EXE의 무인 설치와 설치된 앱의 통합 테스트를 수행합니다. 설치 파일은 `baccarat-windows-x64-installer` 아티팩트로 보관합니다. 코드 서명 인증서는 설정하지 않았으므로 초기 설치 파일은 미서명입니다. 사용자 PC의 실제 사이트 로그인·게임 수집은 별도 검증이 필요합니다. 검사 결과는 [docs/validation.md](docs/validation.md)와 PR checks에서 확인할 수 있습니다.

분석 DB는 Windows `%APPDATA%/baccarat-live-analyzer/baccarat.sqlite`에 저장합니다(Electron `userData`, 개발/패키징 이름에 따라 상위 폴더명이 다를 수 있음). 기존 버전의 DB는 유지합니다. 앱을 닫은 뒤 DB를 백업하세요. Chrome 연결 인증은 별도 로컬 파일과 확장 저장소에 보관하며 로그인 비밀번호·쿠키·게임 세션 URL은 저장하지 않습니다. 새 방식의 사이트 로그인은 일반 Chrome에만 남습니다.

실제 사이트 연결 조건, OCR 한계, 예측의 시간 검증은 [docs/architecture.md](docs/architecture.md)에 정리했습니다.
