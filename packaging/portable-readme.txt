Baccarat Live Analyzer 0.5.8 — 승패 우선 처리 / Windows 무설치

1. ZIP의 모든 파일을 원하는 폴더에 압축 해제합니다.
2. Baccarat Live Analyzer.exe를 더블클릭합니다. 설치 작업은 없습니다.
3. Chrome에서 직접 로그인하고 바카라 게임 창을 엽니다.
4. 프로그램에서 게임 창 선택 → 실제 Chrome 게임 창 선택 → 자동 가져오기 시작.
5. 왼쪽 아래 그림판을 1초마다 가져와 2배 확대하여 판독합니다.
   게임 창을 최소화하지 말고 채워진 색 원 비드로드 6행을 보이게 열어 두세요. 방 이름/회차 숫자는 필요 없습니다.
6. 그림판을 두 번 확인한 뒤 바로 승패를 저장하고 다음4개 A/B/C/D 답과 새 결과의 O/X 적중률을 갱신합니다.
   숫자는 별도 처리하며 숫자 OCR 때문에 승패 저장/채점을 기다리지 않습니다. 기존 예측은 바꾸지 않습니다.
7. 원본 100% / 2배 200%로 그림판을 확인하세요. 확대 이미지를 잡고 드래그하면 이동합니다.
   프로그램 맨 위 Baccarat Live Analyzer 제목을 잡고 드래그하면 프로그램 창이 이동합니다.

이미지는 PC 안에서만 분석하며 파일로 저장하지 않습니다.
그림판 기록 번호는 보이는 첫 결과를 1번으로 센 상대 번호이며 사이트 실제 회차 번호가 아닐 수 있습니다.
그림판의 기존 순서가 바뀌거나 줄어든 화면을 두 번 확인하면 새 기록으로 분리하고 이전 기록을 보존합니다.
다른 방의 그림판 순서가 완전히 같으면 자동 구분하지 못합니다. 새 그림판 기록 버튼을 누르세요.
새 Chrome 창이 열리면 게임 창을 다시 선택합니다. 2배 확대가 인식 성공을 보장하지는 않습니다.
첫 이력 및 수집 중단/방 이동 중 놓친 이력에는 사후 O/X를 매기지 않습니다.
실제 Evolution 화면 판독은 아직 검증하지 않았습니다. 미리보기와 보류 이유로 상태를 확인하세요.

수동 입력도 가능: 자동 가져오기 중지 → 클립보드 이미지 Ctrl+V → 원본 100%/150% 확인 → 저장.
숫자 점수는 0~9입니다. 불확실한 숫자는 비우며 직접 수정할 수 있습니다.
EXE와 resources 등 폴더·파일을 모두 함께 유지하세요.
기존 Windows 사용자별 앱 데이터의 기록은 유지합니다. 자동 베팅은 없습니다.

게임 창 이미지 자동 가져오기 제목 옆에서 실행 버전 0.5.8를 확인하세요.
기존 분석기가 켜져 있으면 새 EXE가 시작되지 않습니다. 기존 프로그램을 종료한 뒤 새 EXE를 다시 실행하세요.
판독 대기에는 원 후보 개수와 기준 갱신 대기를 표시하며, 예전1회차를 현재 기준으로 표시하지 않습니다.
33개 결과가 확정되면33회차 기준34~37, 다음34개가 확인되면34회차 기준35~38로 갱신합니다.

0.5.8: 숫자 그림장을 그대로 사용하세요. T는타이분류이며 초록8은타이/점수8입니다.
청록빛초록을파랑으로세던조건을고쳤습니다. 숫자는별도로읽고흰글자는승패색에포함하지않습니다.
실시간 그림판 모니터는자동으로접히지않습니다. 임시판독실패에는마지막유효이미지와촬영시각을유지합니다.
판독을별도스레드로옮기고그림판영역/변경없는픽셀을재사용하여화면버벅임을줄였습니다.
resources/analysis/board-worker.cjs도함께유지하세요. 모든ZIP파일을새폴더에풀어실행합니다.

화면: 왼쪽 그림판 / 오른쪽 예측·O/X·적중률. 기본 한눈에 보기로 그림판 전체를 표시합니다. 지난 채점과 다음 4회차는 같은 표에서 번호 순서대로 이어지며, 이전 채점 전체는 전체 보기로 펼칩니다. 화면 전체를 스크롤하면 모니터가 유지됩니다.

0.5.8: 시작할 때 요청하신 관리자 암호를 입력합니다. 암호 해제 전에는 통계·입력·캡처를 사용할 수 없습니다. 암호는 평문으로 저장하지 않습니다.
기본 1회차부터 보기는 과거 검증과 실제 사전 예측을 구분해 같은 표에 표시합니다. 과거 검증률은 실시간 적중률에 더하지 않습니다. 실시간 보기로 전환하면 최근 채점과 다음 4회차에 집중합니다.
반복 통계 계산과 동일 이미지 재전송을 줄입니다. 카메라/Windows 캡처 속도 자체는 PC와 창 구성에 따라 달라집니다.

0.5.8: 판독 대기 때 과거 기록표를 접지 않고 유지합니다. 미래 예상 답은 판독 확인까지 대기 표시합니다. 새 회차 추가와 확인 대기/복귀 중 자동 스크롤 보정을 끕니다.
