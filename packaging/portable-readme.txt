Baccarat Live Analyzer 0.5.2 — 그림판만 자동 분석 / Windows 무설치

1. ZIP의 모든 파일을 원하는 폴더에 압축 해제합니다.
2. Baccarat Live Analyzer.exe를 더블클릭합니다. 설치 작업은 없습니다.
3. Chrome에서 직접 로그인하고 바카라 게임 창을 엽니다.
4. 프로그램에서 게임 창 선택 → 실제 Chrome 게임 창 선택 → 자동 가져오기 시작.
5. 왼쪽 아래 그림판을 1초마다 가져와 2배 확대하여 판독합니다.
   게임 창을 최소화하지 말고 채워진 색 원 비드로드 6행을 보이게 열어 두세요. 방 이름/회차 숫자는 필요 없습니다.
6. 그림판을 두 번 확인한 뒤 저장하며 다음 4개 기록의 A/B/C/D 답과 새 결과의 O/X 적중률을 표시합니다.
7. 원본 100% / 2배 200%로 그림판을 확인하세요. 확대 이미지를 잡고 드래그하면 이동합니다.
   프로그램 맨 위 Baccarat Live Analyzer 제목을 잡고 드래그하면 프로그램 창이 이동합니다.

이미지는 PC 안에서만 분석하며 파일로 저장하지 않습니다.
그림판 기록 번호는 보이는 첫 결과를 1번으로 센 상대 번호이며 사이트 실제 회차 번호가 아닐 수 있습니다.
그림판의 기존 순서가 바뀌거나 줄어든 화면을 두 번 확인하면 새 기록으로 분리하고 이전 기록을 보존합니다.
다른 방의 그림판 순서가 완전히 같으면 자동 구분하지 못합니다. 새 그림판 기록 버튼을 누르세요.
새 Chrome 창이 열리면 게임 창을 다시 선택합니다. 2배 확대가 인식 성공을 보장하지는 않습니다.
첫 이력 및 수집 중단/방 이동 중 놓친 이력에는 사후 O/X를 매기지 않습니다.
실제 Evolution 화면 판독은 아직 검증하지 않았습니다. 미리보기와 보류 이유로 상태를 확인하세요.

수동 입력도 가능: 자동 가져오기 중지 → 클립보드 이미지 Ctrl+V → 원본 100%/150% 확인 → 저장.
숫자 점수는 0~9입니다. 불확실한 숫자는 비우며 직접 수정할 수 있습니다.
EXE와 resources 등 폴더·파일을 모두 함께 유지하세요.
기존 Windows 사용자별 앱 데이터의 기록은 유지합니다. 자동 베팅은 없습니다.
