# 검증 기록

0.4.1 (한국 시간 2026-10-14): 단위 테스트 64개 및 Linux Electron 테스트 4개 통과. 추가 테스트는 실제 OS 이미지 클립보드를 사용해 대시보드 Ctrl+V, 방 이름 입력칸 Ctrl+V, 직접 입력칸의 기본 메뉴 붙여넣기, 일반 텍스트 붙여넣기 유지, 이미지 없는 클립보드 오류와 이전 미리보기 제거, 다시 붙여넣기, 확인 전 DB 미저장을 검사합니다. Windows 소스·설치 EXE에서도 같은 검사를 수행하도록 기존 CI에 포함했습니다. 실제 Windows 캡처 도구와 사용자 사이트 화면의 인식률은 별도 확인이 필요합니다.

0.4.0: 단위 테스트 64개 및 Linux Electron 테스트 3개 통과. 작은 475×139 격자에 흰 B/P/T 글자·쌍 표시·붙은 원을 재현한 비드로드 38개(B19/P16/T3)와 빅로드 B/P35개+확인 입력한 T3개를 검사합니다. 제공된 원본 첨부 이미지의 픽셀 파일은 작업 환경에서 접근하지 못해 재현 fixture를 사용했으며 실제 원본을 실행했다고 주장하지 않습니다. 클립보드 이미지 입력(Electron 44 비동기 API), 직접 입력 시작, 다음 결과 수동 기록/O/X, 과거 시뮬레이션의 미래 데이터 제외와 DB 분리를 검증합니다. Windows 설치본 결과는 최신 PR checks에서 확인합니다.

0.3.0: 단위 테스트 53개, Linux Electron 통합 테스트 2개 통과. 새 이미지 테스트는 실제 PNG 파일 선택 → nativeImage 픽셀 판독 → 미리보기 → 수동 수정/확인 → 저장 → 중복 방지 → 재실행 복원을 검증합니다. 이미지 판독 단위 테스트는 6행 순서, 마지막 부분 열, 빈 원 빅로드 제외, 두 그림판 모호성, 중간 누락, 입력 크기를 검사합니다. 실제 사용자의 에볼루션 화면 파일 인식률은 미검증입니다.

Windows CI는 53개 단위 테스트와 3개 데스크톱 테스트를 소스 실행·설치 EXE 실행에서 각각 검사합니다. Chrome 테스트에는 별도 팝업 창과 다른 도메인의 iframe을 추가했고, 설치본에서는 실제 패키지의 확장 파일을 사용합니다. 선택적 탐색 정보/사이트 권한 팝업은 fixture에서 미리 허용합니다. 사용자 Chrome의 실제 권한 팝업과 실제 게임 수집은 별도 검증이 필요합니다. 최신 실행 결과는 PR checks에서 확인하세요.

검증일: 2026-10-13 (한국 시간). 아래 첫 표는 0.1.0 검증 기록입니다. 실제 게임의 예측 우위는 아직 입증되지 않았습니다.

0.2.0은 일반 Chrome + 확장 실행 버튼 + 인증된 localhost 연결로 변경했습니다. 단위 테스트 37개와 Electron 테스트를 통과했습니다. Chrome 확장 실연결·재연결 및 Windows 설치본 검증은 최신 PR checks에서 확인합니다. 실제 에볼루션 게임 결과 프로필과 Chrome OCR은 아직 미검증입니다.

Linux의 `--no-sandbox`는 컨테이너 사용자 네임스페이스 제한 때문에 로컬 fixture 전용 테스트에서만 사용합니다. 해당 `--smoke-test`는 실제 사이트 접속을 거절하고 테스트 전용 DB/세션을 사용합니다. Windows 및 일반 앱 실행에는 적용하지 않습니다.

시험 데이터의 높은 적중률을 실제 게임 정확도로 표현하지 않습니다. 통계는 동일 목표 회차에서 사전에 저장한 A/B/C/D 분포를 비교하며, 과거 데이터의 사후 맞추기는 제외합니다.
