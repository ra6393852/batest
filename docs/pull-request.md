빈 저장소에 Windows용 읽기 전용 바카라 분석 앱을 추가합니다. 로컬 테스트 게임 화면의 결과를 자동 판독해 방·슈·회차별 SQLite에 저장하고, 사전 기록한 A/B/C/D 분포를 실제 관측 결과로 채점합니다. 다음 회차와 2회차 앞 예측을 불변 기록으로 보존하고 공통 회차 적중률, 타이 제외 지표, Brier 점수, 로그 손실 및 CSV를 제공합니다.

원격 사이트에 Node/대시보드 API를 노출하지 않고 자동 베팅 API를 제공하지 않습니다. DOM 수집과 로컬 텍스트 OCR은 어댑터 모듈로 분리했습니다. 실제 box-1515.com 공개 HTTPS 페이지는 200 응답을 확인했지만, 로그인 이후 제공자 화면/iframe/색상 그림장과 내장 브라우저 허용 여부는 미검증이어서 기본 사이트 자동 수집은 비활성입니다. 예측 우위나 다음 판의 정확한 확률은 주장하지 않습니다.
