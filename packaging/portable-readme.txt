Baccarat Live Analyzer 0.4.6 — 클립보드 입력 전용 / Windows 무설치

1. ZIP의 모든 파일을 원하는 폴더에 압축 해제합니다.
2. Baccarat Live Analyzer.exe를 더블클릭합니다.
3. 클립보드에 이미지가 있으면 프로그램에서 Ctrl+V를 누릅니다.
4. 원본 100% / 확대 150%로 인식 결과와 순서를 확인합니다.
   빅로드 초록 표시당 T1회를 기본으로 넣으며 타이 포함 회차와 총개수를 표시합니다.
   원본의 타이 숫자가 2회 이상이면 횟수를 수정하고 확인하세요.
5. 방/슈/첫 기록 번호를 확인한 뒤 확인 체크 → 확인한 그림판 기록 저장을 누릅니다.

새 캡처가 필요할 때만 Win+Shift+S로 6행 그림판 전체를 캡처합니다.
격자선이 약하면 원의 중심/둘레로 빅로드를 다시 읽습니다.
인식 실패 때는 미리보기와 격자/원 후보 수, 중단 이유를 표시합니다. 미확정 결과는 저장하지 않습니다.
EXE와 resources 등의 폴더·파일을 함께 유지하세요.
기록은 기존 Windows 사용자별 앱 데이터 저장 위치에 남습니다.
붙여넣은 이미지는 과거 기록이며 사후 O/X 채점하지 않습니다.
