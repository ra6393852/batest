Windows용 읽기 전용 바카라 분석기를 추가합니다. Chrome 게임 창의 숫자 그림판을 1초마다 수집하고, A/B/C/D의 다음 4회차 답을 결과 전에 저장해 O/X와 누적 적중률을 표시합니다. 그림판 변화로 기록 그룹을 분리하고 SQLite 기록을 보존합니다. 처음 읽은 이력과 수집 중 놓친 결과는 사후 채점하지 않습니다.

0.5.6에서는 큰 상단 미리보기와 별도 패널 스크롤 때문에 예측표를 보기 어려운 화면을 정리합니다. 왼쪽에 수집 상태와 그림판, 오른쪽 위에 A/B/C/D 적중률과 예측표를 배치합니다. 기본 한눈에 보기로 그림판 전체를 표시하고 100%/200% 확대를 유지합니다. 화면 전체가 스크롤되며 왼쪽 모니터는 유지됩니다. 긴 사용 안내와 채점 기준은 접고 중복 보류 안내를 제거합니다.

지난 채점과 다음 4회차를 하나의 표에서 회차 오름차순으로 이어 표시합니다. 기본 최근 7회와 전체 보기 모두 같은 표를 사용합니다. 과거 각 회차는 가장 최근 기준의 채점된 예측을 표시하며, 즉시 다음 회차 예측이 없으면 미리 저장한 2~4회차 예측을 사용해 일괄 업데이트에서도 23→24→25→26→27→28→29→30으로 이어집니다. 기존 예측과 채점은 수정하지 않습니다. 판독 대기에는 저장된 기록의 적중률을 명시하고 이전 그림판의 예상 답은 숨깁니다.

숫자 점수 OCR은 별도 큐이며, 승패 판독은 2배 픽셀과 별도 Node 워커/영역 캐시를 사용합니다. 초록 음영과 파랑을 색상각/채도로 구분하고 실제 본체 색 충돌은 92% 기준으로 보류합니다. 모니터는 판독 대기에도 마지막 정상 이미지를 유지합니다. 실제 실행 버전과 중복 실행 안내를 제공합니다.
