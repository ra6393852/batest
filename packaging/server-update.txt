판매자 서버 업데이트 · 코드 재발급 / 관리 버튼 수정
==================================================
이 파일은 기존 판매자 서버를 고치는 업데이트입니다.
고객용 프로그램은 그대로 사용합니다. 기존 서버 주소와 서명 키도 그대로입니다.

1. 기존 서버가 있는 폴더를 엽니다.
   server.cjs, 서버시작.cmd, license-data 폴더가 함께 있는 곳입니다.
2. 서버 실행 검은 창에서 Ctrl+C를 눌러 서버를 종료합니다.
   Cloudflare 터널 창은 계속 켜 두세요. 이 업데이트 때문에 터널을 다시 만들 필요는 없습니다.
3. 서버가 종료된 뒤 license-data 폴더 전체를 판매자 전용 안전한 곳에 백업합니다.
   이 폴더에는 기존 고객·만료일·서명 키가 있습니다. 삭제하거나 새 폴더로 교체하지 않습니다.
4. 이번 업데이트 ZIP을 별도 폴더에 모두 압축 해제합니다.
   새 server.cjs를 1번의 기존 서버 폴더에 복사하고 [대상 파일 덮어쓰기]를 선택합니다.
   설명서 TXT도 함께 교체할 수 있습니다. license-data 폴더는 그대로 둡니다.
5. 기존 폴더의 서버시작.cmd를 다시 실행합니다. 초기화.cmd는 실행하지 않습니다.
6. Chrome의 기존 관리 화면에서 Ctrl+F5로 새로고침하고 기존 관리자 암호로 로그인합니다.
   로컬 관리 주소: http://127.0.0.1:4380/admin
   [코드 재발급] 버튼이 보이면 새 관리 화면입니다.

코드 분실 / 손님에게 코드 다시 전달
----------------------------------
1. 고객 목록에서 고객 메모·관리번호·코드 끝 8자리로 손님을 찾습니다.
2. 해당 고객의 [코드 재발급]을 누릅니다.
3. 확인창 내용을 확인하고 [새 코드 발급]을 누릅니다.
4. [새 코드 복사]로 BLA-로 시작하는 전체 코드만 복사해 손님에게 전달합니다.

새 코드로 교체되며 이전 코드는 더 이상 등록할 수 없습니다.
같은 관리번호·남은 기간·PC 등록·정상 실행 중인 인증·차단 상태는 그대로 유지됩니다.
등록된 PC를 바꾸려면 별도로 [PC 등록 해제]를 누르세요.
재발급은 기간 연장이나 차단 해제가 아닙니다. 만료된 코드는 기간 연장이 필요합니다.
미사용 코드는 계속 미사용이며 손님이 최초 등록한 날부터 사용 기간이 시작됩니다.
서버는 전체 코드를 저장하지 않습니다. 다시 잃어도 재발급을 반복할 수 있습니다.
여러 번 재발급했다면 가장 마지막에 발급된 코드만 유효합니다.

기간 연장 / PC 등록 해제
----------------------
[연장 기간] 선택 → 고객의 [기간 연장] → 확인창의 [확인].
결과창에 새 만료일을 표시합니다. 표의 최초 발급 기간 표시는 바뀌지 않습니다.
미사용 이용권은 최초 등록 후 연장할 수 있습니다.

고객의 [PC 등록 해제] → 확인창의 [확인].
결과창에 등록 해제와 유지된 만료일을 표시합니다.
PC가 이미 미등록이면 원래 PC 연결이 없는 상태입니다.
기존 실행의 인증 종료까지 새 등록은 최대 2분 기다릴 수 있습니다.

관리 확인창의 [취소]는 실제 변경 없이 닫습니다.
로그인이 1시간 지나 만료됐으면 로그인 화면으로 돌아가며 암호를 다시 입력합니다.
서버 연결 오류는 확인창 안에 표시합니다. 결과가 불분명하면 목록/변경 이력을 확인하세요.
