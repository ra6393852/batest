Baccarat Live Analyzer 0.4.2 — Windows 무설치 버전

1. ZIP의 모든 파일을 원하는 폴더에 압축 해제합니다.
2. Baccarat Live Analyzer.exe를 더블클릭합니다.
3. Chrome에서 그림판을 Win+Shift+S로 캡처합니다.
4. 프로그램으로 돌아와 Ctrl+V를 누릅니다.
5. 인식 결과를 확인하고 확인 체크 → 확인한 그림판 기록 저장을 누릅니다.

EXE와 resources 등의 폴더·파일을 함께 유지하세요.
다음 실행부터 같은 EXE를 더블클릭하면 됩니다.
기록은 Windows 사용자별 앱 데이터 폴더에 저장됩니다.
기존 설치 버전과 같은 Windows 계정의 기록을 사용합니다.

Chrome 확장을 사용할 경우에도 이 EXE를 먼저 실행하세요.
확장은 실행 중인 프로그램에 자동 재연결합니다.
그림판 이미지 붙여넣기는 Chrome 확장 없이 사용할 수 있습니다.
실제 에볼루션 결과 자동 수집은 아직 검증되지 않았습니다.
